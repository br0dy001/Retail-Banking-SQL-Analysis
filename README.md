# Retail-Banking-SQL-Analysis
Analyze fictional banking data using SQL to answer business questions around customers, deposits, loans, transactions, and branch performance.

Tools Used:
SQLite
DB Browser for SQLite
Excel

Dataset:
300 customers
~500 accounts
6,000 transactions
185 loans
10 branches

SQL Commands Used:
SELECT
WHERE
ORDER BY
GROUP BY
HAVING
JOIN
COUNT
AVG
SUM
CTEs
Subqueries
Window functions
